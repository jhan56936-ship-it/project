# BLOCK RIVALS — 디자인 스펙 (2026-06-11)

브라우저에서 바로 실행되는 1인칭 팀 슈팅 게임. 링크만 보내면 친구가 어디서든 접속해
빨강 vs 파랑 팀전을 즐길 수 있다. 로블록스 "Rivals" 스타일.

## 결정 사항 (사용자 확정)

- 플랫폼: 웹 브라우저 게임 (Three.js 3D)
- 접속: 인터넷 어디서나 — 무료 클라우드(Render) 배포
- 범위: 팀 데스매치 + 무기 4종
- 서버: Node.js 단일 서버 (정적 파일 서빙 + WebSocket)
- 비용: 서버 무료 티어, AI API 미사용

## 1. 게임플레이

- **모드**: 팀 데스매치 (빨강 vs 파랑). 먼저 30킬 달성한 팀 승리 → 10초 후 자동 재시작.
- **무기 4종** (스폰 시 선택, 사망 후 변경 가능):
  | 무기 | 특성 | 데미지 | 연사속도 | 탄창 |
  |------|------|--------|----------|------|
  | 돌격소총 | 밸런스형 | 20 | 중간 | 30 |
  | 샷건 | 근거리, 펠릿 8발 확산 | 펠릿당 12 | 느림 | 6 |
  | SMG | 빠른 연사, 낮은 데미지 | 12 | 빠름 | 40 |
  | 스나이퍼 | 한 방(몸샷 100), 느린 볼트 | 100 | 매우 느림 | 5 |
  (수치는 구현 중 플레이 테스트로 조정 가능)
- **조작**: WASD 이동, 마우스 시점(Pointer Lock), 좌클릭 발사, 스페이스 점프,
  Shift 달리기, R 재장전, Tab 스코어보드.
- **시스템**: 체력 100, 사망 시 3초 후 자기 팀 스폰 지역 리스폰, 킬 피드,
  실시간 팀 점수 HUD.
- **맵**: 블록 아레나 1개 — 양 팀 스폰 지역, 엄폐물 블록, 점프 발판, 중앙 격전지.
- **그래픽**: 로블록스 스타일 블록 캐릭터(머리+몸통+팔다리), 팀 색상, 밝은 저폴리곤 룩.

## 2. 접속 흐름

1. 링크 접속 → 닉네임 입력.
2. **빠른 입장**: 공개 방에 자동 입장, 인원 적은 팀으로 배정.
3. **방 코드**: 비공개 방 생성 → 4자리 코드 공유 → 친구 입장.
4. 방당 최대 10명 (5 vs 5). 인원 불균형 시 새 입장자는 적은 팀으로.

## 3. 기술 구조

- **위치**: 기존 저장소 안 `game/` 폴더. 북스토어 코드는 변경하지 않는다.
  - `game/server/` — Node.js 서버
  - `game/client/` — Three.js + Vite 클라이언트 (빌드 결과물을 서버가 서빙)
- **서버 (Node.js + ws)**:
  - 권위(authoritative) 서버: 명중 판정, 데미지, 킬/리스폰, 점수, 승리 판정을 서버가 결정.
  - 클라이언트는 입력·위치를 20Hz로 전송, 서버는 방 상태를 20Hz로 방송.
  - 이동은 클라이언트 주도(즉시 반응) + 서버는 속도/범위 기본 검증(말도 안 되는 순간이동 차단).
  - 무기는 전부 히트스캔(레이캐스트) — 투사체 물리 없음.
- **클라이언트 (Three.js + Vite + TypeScript)**:
  - 내 캐릭터: 로컬 즉시 반응. 다른 플레이어: 스냅샷 보간으로 부드럽게 표시.
  - 1인칭 카메라 + 화면 하단 무기 모델.
- **프로토콜**: JSON WebSocket 메시지 — `join`, `input`(이동/시점), `shoot`,
  `state`(서버 방송), `hit`, `kill`, `respawn`, `score`, `gameover`.
- **배포**: Render 무료 웹 서비스 (WebSocket 지원, 카드 불필요).
  15분 유휴 시 슬립 → 첫 접속 시 약 1분 웨이크업은 무료 티어의 감수 사항.

## 4. 에러 처리

- 연결 끊김: 서버가 플레이어 제거 + 다른 클라이언트에 알림. 클라이언트는 끊김 안내
  + 재접속 버튼.
- 잘못된 메시지/검증 실패: 해당 메시지 무시 (서버 다운 금지).
- 빈 방: 마지막 플레이어가 나가면 방 상태 초기화(공개 방) 또는 제거(코드 방).

## 5. 테스트

- 서버 로직(명중 판정, 팀 배정, 점수, 승리)은 순수 함수로 분리해 단위 테스트.
- 멀티플레이는 브라우저 창 2개 + 헤드리스 ws 봇으로 수동/자동 검증.
- 배포 후 실제 인터넷 경유 접속 확인.

## 6. 구현 순서

1. 로컬에서 혼자 돌아다니는 3D 맵 + 블록 캐릭터.
2. 멀티플레이 동기화 (두 브라우저 창 테스트).
3. 슈팅·체력·킬·리스폰.
4. 무기 4종 + 팀·점수·승리 조건.
5. 방 코드 + 닉네임/HUD UI 다듬기.
6. Render 배포 → 실제 링크 공유.

## 범위 제외 (v1에서 안 함)

상점/화폐, 장비·스킨, 계정/로그인, 랭킹 저장, 투사체 무기(로켓), 모바일 조작,
맵 여러 개, 음성/텍스트 채팅.
